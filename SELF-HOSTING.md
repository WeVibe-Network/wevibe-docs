# Self-Hosting WeVibe Network

This guide walks through running a complete local stack:

1. `wevibed` (wevibe-chain validator + full node)
2. echo-client tooling (wevibe-mcp, wevibe-guard, wevibe-sdk)

## Prerequisites

- Go 1.22+
- Node.js 20+
- Rust 1.76+ (for wevibe-guard/wevibe-sdk builds)
- Docker (optional) for convenience scripts

## Step 1: Run wevibe-chain locally

```bash
git clone https://github.com/WeVibe-Network/wevibe-chain
cd wevibe-chain

# Bootstrap a single-validator network
make init-local # or scripts/init-chain.sh

# Start node
go run ./cmd/wevibed start
```

By default the node listens on:

- Tendermint RPC: `http://localhost:26657`
- gRPC: `http://localhost:9090`

## Step 2: Create an org

```bash
# Set up keys
./bin/wevibed keys add leader --keyring-backend test

# Import helper script to create org with default params
scripts/devnet/create-org.sh leader my-org
```

This burns the registration fee, funds the org treasury with test tokens, and outputs the org ID.

## Step 3: Configure wevibe-mcp

```bash
npm install -g wevibe-mcp

cat <<JSON > ~/.config/echo/mcp.json
{
  "mcpServers": {
    "echo": {
      "command": "wevibe-mcp",
      "env": {
        "WEVIBE_CHAIN_RPC": "http://localhost:26657",
        "WEVIBE_CHAIN_GRPC": "http://localhost:9090",
        "WEVIBE_ORG_ID": "my-org"
      }
    }
  }
}
JSON
```

On first run wevibe-mcp will prompt you to join the org with the invitation generated by the leader.

## Step 4: Run wevibe-guard (optional sidecar)

```bash
git clone https://github.com/WeVibe-Network/echo
cd echo/wevibe-guard
cargo build --release
export WEVIBE_GUARD_BIN="$(pwd)/target/release/wevibe-guard"
```

wevibe-mcp auto-detects the binary when `WEVIBE_GUARD_BIN` is set.

## Step 5: Moderate and approve

- Moderators run the dashboard or CLI to approve pending commitments.
- Approved memories immediately appear in local recall once the transaction finalises.

## Networking notes

- Change `WEVIBE_CHAIN_RPC` / `WEVIBE_CHAIN_GRPC` to point at remote validators when you connect to shared testnets or mainnet.
- If you expose RPC publicly, secure it with firewall rules and TLS via a reverse proxy.

## Cleanup

Stop `wevibed`, delete the data directory (`~/.wevibe-chain` by default), and remove the cached config at `~/.echo/`.
