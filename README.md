# wevibe-docs

Canonical architecture and documentation for the [WeVibe Network](https://github.com/WeVibe-Network).

This repository is the public source of truth for how the network is designed and operated:

- System whitepaper (`WHITEPAPER.md`)
- Cross-module topology (`TOPOLOGY.md`)
- Security model (`SECURITY-MODEL.md`) and key management (`KEY_MANAGEMENT.md`)
- Validator quickstart (`VALIDATOR_QUICKSTART.md`) and org-leader quickstart (`LEADER_QUICKSTART.md`)
- Self-hosting guide (`SELF-HOSTING.md`) and deployment checklist (`DEPLOYMENTCHECKLIST.md`)
- Operational runbooks (`RUNBOOK-*.md`, `RECOVERY_RUNBOOK.md`)
- Retrieval and matching design (`MATCHING_ENGINE.md`, `EVAL-ENCRYPTED-VECTOR-SEARCH.md`)

Code lives in the other WeVibe Network repositories; this repository contains only
documentation. The project is in active alpha development.
