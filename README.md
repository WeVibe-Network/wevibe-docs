# wevibe-docs

Canonical architecture and UX documentation for WeVibe Network.

This repository is the single source of truth for:
- UX flows and gap log (`MASTER.md`)
- Locked architectural decisions (`DECISIONS.md`)
- System whitepaper (`WHITEPAPER.md`)
- Cross-module topology (`TOPOLOGY.md`)
- Validator quickstart (`VALIDATOR_QUICKSTART.md`)
- Operational runbooks (`RUNBOOK-*.md`)
- Security model (`SECURITY-MODEL.md`)

Code lives in the other 10 WeVibe Network repositories. This repository
contains only documentation.
